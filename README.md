# Abdelrahman Seif — Portfolio

A premium personal portfolio built with **pure HTML, CSS, and JavaScript**.

## Features

- Dark theme (default) with light mode toggle
- English / Arabic with full RTL support
- Sticky navbar with active section highlighting
- Animated particle background & smooth scroll animations
- Responsive layout (desktop, tablet, mobile)
- Accessible (keyboard nav, ARIA, focus states)

## Getting Started

Open `index.html` in your browser, or serve locally:

```bash
npx serve .
```

## Customize

- **Content & translations:** edit `js/i18n.js`
- **Styles:** edit `css/styles.css`
- **Interactions:** edit `js/main.js`

Replace the avatar placeholder in `index.html` with your photo when ready.
